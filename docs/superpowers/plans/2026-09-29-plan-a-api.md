> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** All of `apps/api` per `.claude/rules/api.md`:
- auth with a global JWT guard, and profile with onboarding, goals and consent;
- a plan progression the server enforces;
- mock billing, and a coach behind the Plus gate;
- every domain service built red → green → refactor against in-memory adapters;
- then four e2e flows against Postgres, and the API README.

**Architecture:** One NestJS module per area: users, auth, plan, billing, coach.
- Each module is controller → service → repository port (interface + DI token) → Drizzle
  adapter.
- Services throw `AppError(code)`. Plan 0's global filter turns that into `{ code, message }`.
- Request bodies go through `ZodValidationPipe` with the `@forge/contracts` schemas.
- A global `JwtAuthGuard` protects everything except `@Public()` routes.

**Tech Stack:** NestJS 11.2, @nestjs/jwt 11, bcryptjs 3, drizzle-orm 0.45 + postgres.js, zod 4,
Jest 30 + ts-jest + supertest, Postgres 16.

**Spec:** `docs/superpowers/specs/2026-09-28-forge-design.md`. This plan implements §5–§6,
§9.1–§9.2 and the API half of §10 and §11 "Plan A". Plan 0 must be on main first; its Task 3

## Review Focus

Failure modes the spec implies but no spec-listed test covers, most likely first. Each line
names the task that pins it.

1. **Logging in with different casing or spaces** (`  ALEX@forge.test `). This must log into
   the same account. *Task 2 unit test ("whatever the email casing") + Task 8 e2e.*
2. **Completing the same session twice at the same moment** (a double tap or a retry). It must
   advance once, not skip a session. *Task 4 unit test + Task 8 e2e (two concurrent POSTs).*
3. **Two signups with the same email racing each other.** One must get 201 and the other 409
   `EMAIL_TAKEN`, never a 500 from the unique index. *Task 8 e2e.*
4. **`PATCH /me` with only fields it doesn't own** (`{ "email": … }`). It must answer 400
   "Nothing to update." and change nothing. *Task 8 e2e.*
5. **A blank coach message or an unknown product id.** These must answer 400 with readable
   copy ("Type a message first.", "Choose a plan."), not a stack trace. *Task 8 e2e.*

```ts
import type { Goal } from '@forge/contracts';

export const USERS_REPOSITORY = Symbol('USERS_REPOSITORY');

export interface UserRecord {
  id: string;
  email: string;
  passwordHash: string;
  displayName: string | null;
  goals: Goal[]; // in GOALS order
  consentAcceptedAt: Date | null;
  createdAt: Date;
}

export interface NewUser {
  email: string;
  passwordHash: string;
}

export interface UserChanges {
  displayName?: string;
  goals?: Goal[]; // replaces the whole set
  consentAcceptedAt?: Date;
}

export interface UsersRepository {
  /** Throws AppError EMAIL_TAKEN when the email is already registered. */
  create(user: NewUser): Promise<UserRecord>;
  findByEmail(email: string): Promise<UserRecord | null>;
  findById(id: string): Promise<UserRecord | null>;
  /** Applies the changes and returns the updated user, or null when it doesn't exist. */
  update(id: string, changes: UserChanges): Promise<UserRecord | null>;
  delete(id: string): Promise<void>;
}
```

```ts
import { randomUUID } from 'node:crypto';
import { AppError } from '../../src/common/app-error';
import type {
  NewUser,
  UserChanges,
  UserRecord,
  UsersRepository,
} from '../../src/users/users.repository';

export class InMemoryUsersRepository implements UsersRepository {
  private readonly users = new Map<string, UserRecord>();

  create(user: NewUser): Promise<UserRecord> {
    if ([...this.users.values()].some((existing) => existing.email === user.email)) {
      throw new AppError('EMAIL_TAKEN', 'An account with this email already exists.');
    }
    const record: UserRecord = {
      id: randomUUID(),
      email: user.email,
      passwordHash: user.passwordHash,
      displayName: null,
      goals: [],
      consentAcceptedAt: null,
      createdAt: new Date(),
    };
    this.users.set(record.id, record);
    return Promise.resolve(copy(record));
  }

  findByEmail(email: string): Promise<UserRecord | null> {
    const found = [...this.users.values()].find((user) => user.email === email);
    return Promise.resolve(found ? copy(found) : null);
  }

  findById(id: string): Promise<UserRecord | null> {
    const found = this.users.get(id);
    return Promise.resolve(found ? copy(found) : null);
  }

  update(id: string, changes: UserChanges): Promise<UserRecord | null> {
    const found = this.users.get(id);
    if (!found) return Promise.resolve(null);
    const updated: UserRecord = {
      ...found,
      ...changes,
      goals: changes.goals ? [...changes.goals] : found.goals,
    };
    this.users.set(id, updated);
    return Promise.resolve(copy(updated));
  }

  delete(id: string): Promise<void> {
    this.users.delete(id);
    return Promise.resolve();
  }
}

function copy(user: UserRecord): UserRecord {
  return { ...user, goals: [...user.goals] };
}
```

```ts
import type { UpdateMeBody, User } from '@forge/contracts';
import { Inject, Injectable } from '@nestjs/common';
import { AppError } from '../common/app-error';
import {
  USERS_REPOSITORY,
  type UserChanges,
  type UserRecord,
  type UsersRepository,
} from './users.repository';

@Injectable()
export class UsersService {
  constructor(@Inject(USERS_REPOSITORY) private readonly users: UsersRepository) {}

  async getMe(userId: string): Promise<User> {
    return toUser(await this.requireUser(userId));
  }

  async updateMe(userId: string, body: UpdateMeBody): Promise<User> {
    const current = await this.requireUser(userId);
    const changes: UserChanges = {};
    if (body.displayName !== undefined) changes.displayName = body.displayName;
    if (body.goals !== undefined) changes.goals = body.goals;
    // Consent is a fact with a date: set once, never overwritten (deleting the account revokes it).
    if (body.acceptConsent && current.consentAcceptedAt === null) {
      changes.consentAcceptedAt = new Date();
    }
    const updated = await this.users.update(userId, changes);
    if (!updated) throw signInAgain();
    return toUser(updated);
  }

  async deleteMe(userId: string): Promise<void> {
    await this.users.delete(userId);
  }

  private async requireUser(userId: string): Promise<UserRecord> {
    const user = await this.users.findById(userId);
    if (!user) throw signInAgain();
    return user;
  }
}

export function toUser(record: UserRecord): User {
  return {
    id: record.id,
    email: record.email,
    displayName: record.displayName,
    goals: record.goals,
    consentAcceptedAt: record.consentAcceptedAt?.toISOString() ?? null,
    onboarded:
      record.displayName !== null && record.goals.length > 0 && record.consentAcceptedAt !== null,
  };
}

function signInAgain(): AppError {
  return new AppError('UNAUTHORIZED', 'Please sign in again.');
}
```

```ts
import type { AuthResponse, LoginBody, SignupBody } from '@forge/contracts';
import { Inject, Injectable } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { compare, hash } from 'bcryptjs';
import { AppError } from '../common/app-error';
import { USERS_REPOSITORY, type UserRecord, type UsersRepository } from '../users/users.repository';
import { toUser } from '../users/users.service';

const BCRYPT_COST = 10;
// Compared against when the email is unknown, so a login takes as long whether or not the
// account exists (no user enumeration through timing). Hash of a throwaway string.
const DUMMY_HASH = '$2b$10$rvvMb2uRs47ULOEAFdkg7Ou1FZXUp/yrtZ1x1ciRHOx9kg5WJ/sYO';

@Injectable()
export class AuthService {
  constructor(
    @Inject(USERS_REPOSITORY) private readonly users: UsersRepository,
    private readonly jwt: JwtService,
  ) {}

  async signup(body: SignupBody): Promise<AuthResponse> {
    if (await this.users.findByEmail(body.email)) {
      throw new AppError('EMAIL_TAKEN', 'An account with this email already exists.');
    }
    const passwordHash = await hash(body.password, BCRYPT_COST);
    return this.session(await this.users.create({ email: body.email, passwordHash }));
  }

  async login(body: LoginBody): Promise<AuthResponse> {
    const user = await this.users.findByEmail(body.email);
    const matches = await compare(body.password, user?.passwordHash ?? DUMMY_HASH);
    if (!user || !matches) {
      throw new AppError('INVALID_CREDENTIALS', 'Email or password is incorrect.');
    }
    return this.session(user);
  }

  private async session(user: UserRecord): Promise<AuthResponse> {
    return { token: await this.jwt.signAsync({ sub: user.id }), user: toUser(user) };
  }
}
```

```ts
import { Inject, Injectable, type CanActivate, type ExecutionContext } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { JwtService } from '@nestjs/jwt';
import { AppError } from '../common/app-error';
import { USERS_REPOSITORY, type UsersRepository } from '../users/users.repository';
import type { AuthenticatedRequest } from './authenticated-request';
import { IS_PUBLIC } from './public.decorator';

// Registered globally (APP_GUARD): every route needs a bearer token unless it is @Public().
@Injectable()
export class JwtAuthGuard implements CanActivate {
  constructor(
    private readonly reflector: Reflector,
    private readonly jwt: JwtService,
    @Inject(USERS_REPOSITORY) private readonly users: UsersRepository,
  ) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    const isPublic = this.reflector.getAllAndOverride<boolean>(IS_PUBLIC, [
      context.getHandler(),
      context.getClass(),
    ]);
    if (isPublic) return true;

    const request = context.switchToHttp().getRequest<AuthenticatedRequest>();
    const token = bearerToken(request.headers.authorization);
    const payload = token
      ? await this.jwt.verifyAsync<{ sub?: unknown }>(token).catch(() => null)
      : null;
    const userId = typeof payload?.sub === 'string' ? payload.sub : null;
    // A token outlives a deleted account; the user must still exist.
    if (!userId || !(await this.users.findById(userId))) {
      throw new AppError('UNAUTHORIZED', 'Please sign in again.');
    }
    request.userId = userId;
    return true;
  }
}

function bearerToken(header: string | undefined): string | null {
  const [scheme, token] = header?.split(' ') ?? [];
  return scheme === 'Bearer' && token ? token : null;
}
```

```ts
export function isUniqueViolation(error: unknown): boolean {
  const code = (value: unknown): unknown =>
    typeof value === 'object' && value !== null && 'code' in value ? value.code : undefined;
  return code(error) === '23505' || (error instanceof Error && code(error.cause) === '23505');
```

```ts
import type { Goal } from '@forge/contracts';
import { Inject, Injectable } from '@nestjs/common';
import { asc, eq } from 'drizzle-orm';
import { AppError } from '../common/app-error';
import { DB, type Database } from '../db/db.module';
import { isUniqueViolation } from '../db/postgres-errors';
import { userGoals, users } from '../db/schema';
import type { NewUser, UserChanges, UserRecord, UsersRepository } from './users.repository';

type UserRow = typeof users.$inferSelect;
type Reader = Pick<Database, 'select'>;

@Injectable()
export class DrizzleUsersRepository implements UsersRepository {
  constructor(@Inject(DB) private readonly db: Database) {}

  async create(user: NewUser): Promise<UserRecord> {
    try {
      const [row] = await this.db.insert(users).values(user).returning();
      return toRecord(row, []);
    } catch (error) {
      // Two signups racing past AuthService's pre-check: the unique index decides.
      if (isUniqueViolation(error)) {
        throw new AppError('EMAIL_TAKEN', 'An account with this email already exists.');
      }
      throw error;
    }
  }

  async findByEmail(email: string): Promise<UserRecord | null> {
    const [row] = await this.db.select().from(users).where(eq(users.email, email));
    return row ? toRecord(row, await goalsOf(this.db, row.id)) : null;
  }

  async findById(id: string): Promise<UserRecord | null> {
    const [row] = await this.db.select().from(users).where(eq(users.id, id));
    return row ? toRecord(row, await goalsOf(this.db, row.id)) : null;
  }

  async update(id: string, changes: UserChanges): Promise<UserRecord | null> {
    // One transaction, so a reader never sees a half-replaced goals set.
    return this.db.transaction(async (tx) => {
      const { goals, ...columns } = changes;
      if (Object.keys(columns).length > 0) {
        await tx.update(users).set(columns).where(eq(users.id, id));
      }
      if (goals) {
        await tx.delete(userGoals).where(eq(userGoals.userId, id));
        if (goals.length > 0) {
          await tx.insert(userGoals).values(goals.map((goal) => ({ userId: id, goal })));
        }
      }
      const [row] = await tx.select().from(users).where(eq(users.id, id));
      return row ? toRecord(row, await goalsOf(tx, id)) : null;
    });
  }

  async delete(id: string): Promise<void> {
    // user_goals, coach_messages and entitlements go with it (ON DELETE CASCADE).
    await this.db.delete(users).where(eq(users.id, id));
  }
}

// Postgres orders enum values by declaration order, which is GOALS order.
async function goalsOf(reader: Reader, userId: string): Promise<Goal[]> {
  const rows = await reader
    .select({ goal: userGoals.goal })
    .from(userGoals)
    .where(eq(userGoals.userId, userId))
    .orderBy(asc(userGoals.goal));
  return rows.map((row) => row.goal);
}

function toRecord(row: UserRow, goals: Goal[]): UserRecord {
  return {
    id: row.id,
    email: row.email,
    passwordHash: row.passwordHash,
    displayName: row.displayName,
    goals,
    consentAcceptedAt: row.consentAcceptedAt,
    createdAt: row.createdAt,
  };
}
```

```ts
import type { PlanView, SessionStatus } from '@forge/contracts';
import { Inject, Injectable } from '@nestjs/common';
import { AppError } from '../common/app-error';
import { PLAN_REPOSITORY, type PlanRepository } from './plan.repository';
import { PLAN_TEMPLATE } from './plan.template';

@Injectable()
export class PlanService {
  constructor(@Inject(PLAN_REPOSITORY) private readonly progress: PlanRepository) {}

  async getPlan(userId: string): Promise<PlanView> {
    return buildPlanView(await this.progress.getCompletedCount(userId));
  }

  // Server-enforced order: only the open session (index == count) can be completed.
  async complete(userId: string, sessionId: string): Promise<PlanView> {
    const index = PLAN_TEMPLATE.findIndex((session) => session.id === sessionId);
    if (index === -1) throw new AppError('SESSION_NOT_FOUND', 'That session does not exist.');
    const count = await this.progress.getCompletedCount(userId);
    if (index < count) return buildPlanView(count);
    if (index > count) {
      throw new AppError('SESSION_LOCKED', `Finish ${PLAN_TEMPLATE[count].title} first.`);
    }
    return buildPlanView(await this.progress.advanceFrom(userId, index));
  }

  async reset(userId: string): Promise<PlanView> {
    await this.progress.reset(userId);
    return buildPlanView(0);
  }
}

// Decision A: index < count → completed, == count → open, > count → locked.
export function buildPlanView(completedCount: number): PlanView {
  const statusAt = (index: number): SessionStatus =>
    index < completedCount ? 'completed' : index === completedCount ? 'open' : 'locked';
  return {
    sessions: PLAN_TEMPLATE.map((session, index) => ({
      id: session.id,
      number: index + 1,
      title: session.title,
      subtitle: session.subtitle,
      durationMinutes: session.durationMinutes,
      blocks: session.blocks.map((block) => ({ ...block })),
      status: statusAt(index),
    })),
    completedCount,
    totalCount: PLAN_TEMPLATE.length,
    nextSessionId: PLAN_TEMPLATE[completedCount]?.id ?? null,
  };
}
```

```ts
import { Inject, Injectable } from '@nestjs/common';
import { and, eq, sql } from 'drizzle-orm';
import { DB, type Database } from '../db/db.module';
import { users } from '../db/schema';
import type { PlanRepository } from './plan.repository';

@Injectable()
export class DrizzlePlanRepository implements PlanRepository {
  constructor(@Inject(DB) private readonly db: Database) {}

  async getCompletedCount(userId: string): Promise<number> {
    const [row] = await this.db
      .select({ completedCount: users.completedCount })
      .from(users)
      .where(eq(users.id, userId));
    return row?.completedCount ?? 0;
  }

  async advanceFrom(userId: string, expected: number): Promise<number> {
    const [row] = await this.db
      .update(users)
      .set({ completedCount: sql`${users.completedCount} + 1` })
      .where(and(eq(users.id, userId), eq(users.completedCount, expected)))
      .returning({ completedCount: users.completedCount });
    // No row changed: a concurrent request advanced it first. Report where it is now.
    return row ? row.completedCount : this.getCompletedCount(userId);
  }

  async reset(userId: string): Promise<void> {
    await this.db.update(users).set({ completedCount: 0 }).where(eq(users.id, userId));
  }
}
```

```ts
import type { Entitlement, ProductId } from '@forge/contracts';
import { Inject, Injectable } from '@nestjs/common';
import {
  BILLING_REPOSITORY,
  type BillingRepository,
  type PurchaseRecord,
} from './billing.repository';

const TRIAL_DAYS = 7;
const DAY_MS = 24 * 60 * 60 * 1000;

// Mock billing: no store, no charge. The purchase record lives on the server, so the server
// stays the source of truth for the entitlement, as it would with real store receipts.
@Injectable()
export class BillingService {
  constructor(@Inject(BILLING_REPOSITORY) private readonly purchases: BillingRepository) {}

  async get(userId: string): Promise<Entitlement> {
    return toEntitlement(await this.purchases.find(userId));
  }

  async purchase(userId: string, productId: ProductId): Promise<Entitlement> {
    const existing = await this.purchases.find(userId);
    // One trial per account: switching products keeps the original trial end.
    const trialEndsAt = existing?.trialEndsAt ?? new Date(Date.now() + TRIAL_DAYS * DAY_MS);
    return toEntitlement(await this.purchases.upsert(userId, { productId, trialEndsAt }));
  }

  // In production this would re-validate store receipts. Here the record is already on the
  // server, so restoring means re-reading it; the app says "nothing to restore" if still free.
  restore(userId: string): Promise<Entitlement> {
    return this.get(userId);
  }
}

export function toEntitlement(purchase: PurchaseRecord | null): Entitlement {
  return purchase
    ? {
        tier: 'plus',
        productId: purchase.productId,
        trialEndsAt: purchase.trialEndsAt.toISOString(),
      }
    : { tier: 'free', productId: null, trialEndsAt: null };
}
```

```ts
import { GOALS, type Goal } from '@forge/contracts';

// The "model" behind the coach: a pure, deterministic function of what the user said and
// where they are. No randomness — the same input always produces the same reply.

export interface NextSession {
  title: string;
  durationMinutes: number;
  blockCount: number;
}

export interface CoachContext {
  displayName: string | null;
  goals: Goal[];
  completedCount: number;
  totalCount: number;
  next: NextSession | null; // null when the plan is complete
  firstSessionTitle: string;
}

export type Intent = 'recovery' | 'warmUp' | 'shortOnTime' | 'consistency' | 'next' | 'fallback';

// First match wins, so the order is the precedence.
const INTENT_KEYWORDS: [Exclude<Intent, 'fallback'>, string[]][] = [
  ['recovery', ['sore', 'pain', 'hurt', 'rest', 'recover']],
  ['warmUp', ['warm', 'mobility', 'stretch']],
  ['shortOnTime', ['time', 'busy', 'quick', 'short', 'minutes']],
  ['consistency', ['consisten', 'habit', 'motivat', 'skip', 'tired']],
  ['next', ['next', 'today', 'session', 'plan']],
];

const GOAL_PHRASES: Record<Goal, string> = {
  get_stronger: 'getting stronger',
  move_daily: 'moving every day',
  build_habit: 'building a habit that sticks',
};

export function detectIntent(message: string): Intent {
  const text = message.toLowerCase();
  const match = INTENT_KEYWORDS.find(([, words]) => words.some((word) => text.includes(word)));
  return match?.[0] ?? 'fallback';
}

/** "a", "a and b" or "a, b and c" in GOALS order; "training" when there are no goals. */
export function goalsPhrase(goals: Goal[]): string {
  const phrases = GOALS.filter((goal) => goals.includes(goal)).map((goal) => GOAL_PHRASES[goal]);
  if (phrases.length === 0) return 'training';
  if (phrases.length === 1) return phrases[0];
  return `${phrases.slice(0, -1).join(', ')} and ${phrases[phrases.length - 1]}`;
}

export function progressLine(context: CoachContext): string {
  const { completedCount, totalCount, next, firstSessionTitle } = context;
  if (completedCount === 0)
    return `You haven't started yet — ${next?.title ?? firstSessionTitle} is open.`;
  if (!next) return `You've completed all ${totalCount} sessions.`;
  return `You've completed ${completedCount} of ${totalCount} sessions; ${next.title} is up next.`;
}

export function composeCoachReply(context: CoachContext, message: string): string {
  const name = context.displayName ?? 'there';
  const goals = goalsPhrase(context.goals);
  const { next } = context;

  const bodies: Record<Intent, () => string> = {
    recovery: () =>
      `${name}, some soreness after a new session is normal; sharp pain isn't — stop and get it checked. Easy walking helps you recover and keep ${goals}.`,
    warmUp: () =>
      `Start easy, ${name}: five minutes of mobility for hips, shoulders and ankles, then a few slow reps of your first exercise. It's the cheapest win for ${goals}.`,
    shortOnTime: () =>
      `Short on time, ${name}? Do the warm-up and main set of ${next?.title ?? context.firstSessionTitle} and skip the rest. Consistency beats length when you're ${goals}.`,
    consistency: () =>
      `${name}, tie training to something you already do every day and keep the bar low — one session this week is a real win for ${goals}.`,
    next: () =>
      next
        ? `${name}, your next session is ${next.title}: ${next.durationMinutes} minutes across ${next.blockCount} blocks, built for ${goals}. Keep the main set steady and finish every block.`
        : `${name}, the plan is done. Restart it from the Plan tab and aim for smoother reps on the second pass — that's how progress compounds when you're ${goals}.`,
    fallback: () =>
      `Good question, ${name}. I can help with your next session, warming up, short workouts or staying consistent while you're ${goals}.`,
  };

  return `${bodies[detectIntent(message)]()} ${progressLine(context)}`;
}
```

```ts
import type { CoachRole } from '@forge/contracts';
import type { CoachMessageRecord, CoachRepository } from '../../src/coach/coach.repository';

export class InMemoryCoachRepository implements CoachRepository {
  private nextId = 1;
  private readonly byUser = new Map<string, CoachMessageRecord[]>();

  listRecent(userId: string, limit: number): Promise<CoachMessageRecord[]> {
    const messages = this.byUser.get(userId) ?? [];
    return Promise.resolve(messages.slice(-limit).map((message) => ({ ...message })));
  }

  append(userId: string, role: CoachRole, text: string): Promise<CoachMessageRecord> {
    const message: CoachMessageRecord = { id: this.nextId++, role, text, createdAt: new Date() };
    this.byUser.set(userId, [...(this.byUser.get(userId) ?? []), message]);
    return Promise.resolve({ ...message });
  }
}
```

```ts
import type { CoachMessage, PlanView, SendCoachMessageResponse, User } from '@forge/contracts';
import { Inject, Injectable } from '@nestjs/common';
import { BillingService } from '../billing/billing.service';
import { AppError } from '../common/app-error';
import { PlanService } from '../plan/plan.service';
import { UsersService } from '../users/users.service';
import { composeCoachReply, type CoachContext } from './coach-reply';
import {
  COACH_REPOSITORY,
  type CoachMessageRecord,
  type CoachRepository,
} from './coach.repository';

export const COACH_DELAY = Symbol('COACH_DELAY');
/** Simulated model latency. Production: 600–1200 ms. Tests: no wait. */
export type CoachDelay = () => Promise<void>;

const HISTORY_LIMIT = 100;

@Injectable()
export class CoachService {
  constructor(
    @Inject(COACH_REPOSITORY) private readonly messages: CoachRepository,
    private readonly users: UsersService,
    private readonly plan: PlanService,
    private readonly billing: BillingService,
    @Inject(COACH_DELAY) private readonly delay: CoachDelay,
  ) {}

  async history(userId: string): Promise<CoachMessage[]> {
    await this.requirePlus(userId);
    const records = await this.messages.listRecent(userId, HISTORY_LIMIT);
    return records.map(toCoachMessage);
  }

  async send(userId: string, text: string): Promise<SendCoachMessageResponse> {
    await this.requirePlus(userId);
    const message = await this.messages.append(userId, 'user', text);
    const [user, plan] = await Promise.all([this.users.getMe(userId), this.plan.getPlan(userId)]);
    const replyText = composeCoachReply(toCoachContext(user, plan), text);
    await this.delay();
    const reply = await this.messages.append(userId, 'coach', replyText);
    return { message: toCoachMessage(message), reply: toCoachMessage(reply) };
  }

  // The paywall is enforced here, not only in the app.
  private async requirePlus(userId: string): Promise<void> {
    const { tier } = await this.billing.get(userId);
    if (tier !== 'plus') throw new AppError('PLUS_REQUIRED', 'Coach is part of Forge Plus.');
  }
}

function toCoachContext(user: User, plan: PlanView): CoachContext {
  const next = plan.sessions.find((session) => session.id === plan.nextSessionId);
  return {
    displayName: user.displayName,
    goals: user.goals,
    completedCount: plan.completedCount,
    totalCount: plan.totalCount,
    next: next
      ? { title: next.title, durationMinutes: next.durationMinutes, blockCount: next.blocks.length }
      : null,
    firstSessionTitle: plan.sessions[0].title,
  };
}

function toCoachMessage(record: CoachMessageRecord): CoachMessage {
  return {
    id: String(record.id),
    role: record.role,
    text: record.text,
    createdAt: record.createdAt.toISOString(),
  };
}
```

```ts
import { Inject, Injectable } from '@nestjs/common';
import { desc, eq } from 'drizzle-orm';
import { DB, type Database } from '../db/db.module';
import { coachMessages } from '../db/schema';
import type { CoachMessageRecord, CoachRepository } from './coach.repository';

const columns = {
  id: coachMessages.id,
  role: coachMessages.role,
  text: coachMessages.text,
  createdAt: coachMessages.createdAt,
};

@Injectable()
export class DrizzleCoachRepository implements CoachRepository {
  constructor(@Inject(DB) private readonly db: Database) {}

  async listRecent(userId: string, limit: number): Promise<CoachMessageRecord[]> {
    const newestFirst = await this.db
      .select(columns)
      .from(coachMessages)
      .where(eq(coachMessages.userId, userId))
      .orderBy(desc(coachMessages.id))
      .limit(limit);
    return newestFirst.reverse();
  }

  async append(userId: string, role: CoachRole, text: string): Promise<CoachMessageRecord> {
    const [row] = await this.db
      .insert(coachMessages)
      .values({ userId, role, text })
      .returning(columns);
    return row;
  }
}
```

```ts
import request from 'supertest';
import { bearer, createApp, signUp, type TestApp } from './e2e-helpers';

describe('Plan order (e2e)', () => {

  it('enforces the order on the server, end to end', async () => {
    const fresh = await request(app.getHttpServer()).get('/plan').set(bearer(token)).expect(200);
    expect(statuses(fresh.body as PlanView)).toEqual(['open', 'locked', 'locked']);

    const locked = await complete('forge').expect(409);
    expect(locked.body).toEqual({ code: 'SESSION_LOCKED', message: 'Finish Foundation first.' });

    const first = await complete('foundation').expect(200);
    expect(statuses(first.body as PlanView)).toEqual(['completed', 'open', 'locked']);

    const again = await complete('foundation').expect(200);
    expect((again.body as PlanView).completedCount).toBe(1);

    await complete('build').expect(200);
    const reset = await request(app.getHttpServer())
      .post('/plan/reset')
      .set(bearer(token))
      .expect(200);
    expect(reset.body).toMatchObject({ completedCount: 0, nextSessionId: 'foundation' });

    const reread = await request(app.getHttpServer()).get('/plan').set(bearer(token)).expect(200);
    expect(statuses(reread.body as PlanView)).toEqual(['open', 'locked', 'locked']);
  });

  it('advances once when the same completion is sent twice at the same moment', async () => {
    const { token: other } = await signUp(app);
    const send = () =>
      request(app.getHttpServer()).post('/plan/sessions/foundation/complete').set(bearer(other));

    expect((plan.body as PlanView).completedCount).toBe(1);
```

````markdown
# @forge/api

NestJS 11 REST API for Forge, on Postgres 16 via Drizzle. Every route except `/auth/*` needs
`Authorization: Bearer <jwt>`, and every query is scoped by the token's user id. Errors always
look like `{ "code": "...", "message": "..." }`, and `message` is safe to show to a user.

## Run it

From the repo root:

```bash
docker compose up -d --wait
cp apps/api/.env.example apps/api/.env
pnpm db:push
pnpm dev:api
```

| Variable | Default | Meaning |
|---|---|---|
| `DATABASE_URL` | docker-compose `forge` | Postgres connection. A Supabase transaction pooler (port 6543) automatically disables prepared statements. |
| `TEST_DATABASE_URL` | docker-compose `forge_test` | e2e only |
| `JWT_SECRET` | — (≥ 32 chars) | HS256 signing key; tokens last 30 days |
| `PORT` | `3000` | Listens on `0.0.0.0`, so phones on the LAN can connect |
| `COACH_LATENCY_MIN_MS` / `COACH_LATENCY_MAX_MS` | `600` / `1200` | Simulated coach "thinking" time |

## Endpoints

| Endpoint | Auth | Success | Notable errors |
|---|---|---|---|
| `POST /auth/signup` | public | 201 `{ token, user }` | 409 `EMAIL_TAKEN` |
| `POST /auth/login` | public | 200 `{ token, user }` | 401 `INVALID_CREDENTIALS` |
| `GET /me` · `PATCH /me` · `DELETE /me` | bearer | 200 user · 200 user · 204 | 400 `VALIDATION_FAILED` |
| `GET /plan` | bearer | 200 plan | — |
| `POST /plan/sessions/:id/complete` | bearer | 200 plan (a repeat is a no-op) | 404 `SESSION_NOT_FOUND`, 409 `SESSION_LOCKED` |
| `POST /plan/reset` | bearer | 200 plan | — |
| `GET /coach/messages` · `POST /coach/messages` | bearer | 200 history · 201 `{ message, reply }` | 403 `PLUS_REQUIRED` |
| `GET /billing/entitlement` · `POST /billing/mock-purchase` · `POST /billing/mock-restore` | bearer | 200 entitlement | 400 `VALIDATION_FAILED` |

## How it's built

- **One module per area** (users, auth, plan, billing, coach): controller → service →
  repository port → Drizzle adapter. Controllers only do HTTP; services hold the rules and
  throw `AppError(code)`; the global `HttpErrorFilter` maps codes to statuses.
- **Plan progress is one number** (`users.completed_count`). Statuses are derived from the
  static three-session template. Completing is a compare-and-set, so a double tap can't skip
  a session.
- **Validation** uses the `@forge/contracts` zod schemas through `ZodValidationPipe`. The
  schemas' messages are the copy the app shows.
- **The coach** is a pure, deterministic `composeCoachReply()` (name + goals + progress), with
  an injected delay. Both coach endpoints require Plus, and the server enforces that.
````
